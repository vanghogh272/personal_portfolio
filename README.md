# Sana -- 3D Creator

A dark, motion-led 3D creator landing page built with React, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually `http://localhost:5173/`.

## Build for production

```bash
npm run build
npm run preview
```

To generate a production sitemap and a `Sitemap:` entry in `robots.txt`, set the real deployed URL during the build:

```bash
SITE_URL=https://your-real-domain.example npm run build
```

On Windows PowerShell:

```powershell
$env:SITE_URL="https://your-real-domain.example"; npm run build
```

The page keeps the existing external visual assets so the original design remains unchanged.
